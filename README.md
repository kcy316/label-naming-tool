# label-naming-tool

AI로 생성한 학습용 이미지 수천 장을 `{class_name}_{번호}.png`로 일괄 변경하고, 클래스별 번호와 작업 이력을 장부로 관리하는 CLI 도구입니다. Python 표준 라이브러리만 사용합니다.

```
AI 모델 이미지 학습을 위한 생 무, 통무 또는 껍질째 썬 형태, ..._grid_003_r02_c04.png
                                   ↓
                            radish_1376.png
```

## 배경

YOLO 식재료 모델의 학습 데이터를 보충하려고 클래스별 프롬프트로 4×4 그리드 이미지를 생성·분할한 뒤, 라벨링 전에 이름을 바꿔 S3에 업로드했습니다. 이 단계를 손으로 하면:

- 긴 한국어 프롬프트 파일명을 읽고 클래스를 골라내야 하고
- 업로드 후 로컬에 남지 않아 이어 붙일 마지막 번호를 알 수 없고
- 여러 사람이 보충한 내역을 관리표에 수작업으로 적어야 하고
- 잘못 바꾸면 되돌릴 방법이 없었습니다.

## 주요 기능

- **keyword 매칭** — 파일명에 든 keyword로 클래스 판별. 한 파일이 keyword 두 개 이상에 걸리면 **아무것도 바꾸지 않고 중단**
- **번호 장부** — `classes.csv`에 클래스별 다음 번호를 저장하고 적용 시 자동 갱신. 이미지가 폴더에 없어도 번호가 이어짐
- **미리보기 기본** — `--apply` 없이는 결과만 출력
- **되돌리기** — 파일을 바꾸기 전에 `logs/{작업ID}.csv`에 매핑을 먼저 기록. 작업 단위로 복구
- **이력·현황** — `history.csv`에 이력을 쌓고 `--status`로 관리표용 누적 현황 출력

## 빠른 시작

Python 3.9 이상.

```bash
python demo/make_sample.py                      # 샘플 이미지 112장 생성
python rename.py                                # 미리보기
python rename.py --apply                        # 적용
python rename.py --status                       # 클래스별 누적 현황 + status.csv
python rename.py --undo 20261031_213859 --apply # 되돌리기 (작업ID는 적용 시 출력)
```

```
한글명       class_name             found  rename  left  range
무         radish                    32      32     0  radish_1001 ~ radish_1032
베이컨       bacon                     32      20    12  bacon_1001 ~ bacon_1020
...
[WARN] keyword 가 없어 건너뛰는 파일 16장 — classes.csv 에 keyword 를 추가하세요
```

| 옵션 | 설명 |
|------|------|
| `--apply` | 실제로 변경 (없으면 미리보기) |
| `--dir` | 분할 이미지 폴더 (기본 `output/splits`) |
| `--grid-dir` | 그리드 원본 폴더. 번호 순서에 생성 시각 참고 (기본 `output/grids`) |
| `--status` | 누적 현황 출력 및 `status.csv` 저장 |
| `--undo 작업ID` | 해당 작업 되돌리기 |

## classes.csv

```csv
한글명,class_name,keyword,start,limit
무,radish,생 무,1001,
베이컨,bacon,생 베이컨,1001,20
계란,egg,,1001,
```

- `keyword`: 파일명에 들어 있는 문자열. 비우면 건너뜀
- `start`: 다음 번호. `--apply` 후 자동 갱신
- `limit`: 이번 작업 최대 장수. 비우면 전부

엑셀 호환을 위해 UTF-8 BOM으로 읽고 씁니다.

## 설계 포인트

**애매하면 멈춘다.** 짧은 keyword는 엉뚱한 프롬프트에 걸리기 쉽습니다(`가지` → "가지런히", `흰쌀` → "흰쌀밥"). 일부만 바꾸면 잘못된 라벨이 섞여 업로드될 수 있으므로, 충돌·이름 중복이 하나라도 있으면 전체를 중단합니다.

**되돌리기는 장부와 일관되게.** 이미 업로드된 파일은 건너뛰고, 장부의 `start`는 그 작업이 해당 클래스의 마지막 작업일 때만 되돌립니다. 같은 작업을 두 번 되돌릴 수 없습니다.

**번호 순서는 재현 가능하게.** 그리드 생성 시각 → 그리드 번호 → 행 → 열 순으로 매겨, 미리보기와 적용 결과가 항상 같습니다.

## 실제 사용 결과

식재료 데이터셋 보충에서 6회 작업, 61개 클래스, 누적 약 13,600장(최대 1회 약 8,700장)을 변경했고, `--status` 결과로 팀 관리표의 수작업 기록을 대체했습니다.
